# 涨停成本回补战法（试验版）

> **版本**：v1.0  
> **更新日期**：2026-07-10  
> **定位**：短线（1～3 个交易日）  
> **性质**：个人交易规则留存，不构成投资建议  

---

## 一、策略一句话

近 **3** 个交易日出现放量涨停（1～2 板优先），以涨停日均价（或典型价）为成本线 \(C\)；股价缩量跌至成本线下方完成清洗；在大盘非崩、靠近主线、资金未撤离的前提下，于 **14:00～14:45** 分时止跌后小仓买入；目标是 **次日反抽至成本线附近或上方** 卖出；跌破止损位立即离场。

**口诀：**

```
有板有量定成本，跌下成本看缩量；
主线还在两点半，止跌小仓挂止损；
次日冲C就兑现，破位不扛下一单。
```

---

## 二、核心逻辑

| 环节 | 假设 |
|------|------|
| 涨停 | 主力拉板花费较高，成本抬升 |
| 回调 | 股价被砸到成本线下方，完成清洗 |
| 未走 | 回调缩量、未破关键低点，资金未明显撤离 |
| 买入 | 下午盘面洗干净、分时止跌 |
| 卖出 | 次日回拉到成本区，兑现回补利润 |

**利润来源定位：** 回到成本区的回补空间，**不贪主升浪**。

**模式归属：** 情绪/短线（闷杀回补）。  
**不做：** 中线逻辑仓、无涨停结构的纯超跌抄底。  
**账户：** 与中线逻辑仓（如半导体设备）分开额度，互不挪用。

---

## 三、关键定义（写死）

### 3.1 成本线 \(C\)

| 方案 | 算法 | 说明 |
|------|------|------|
| **默认 A** | 涨停日均价 = 成交额 ÷ 成交量 | 最贴近「拉板花的钱」 |
| 备选 B | 典型价 = (开 + 高 + 低 + 收) / 4 | 无均价数据时用 |
| 备选 C | 涨停日起区间筹码峰 / 分时黄线 | 更稳，稍滞后 |

- 若近 3 日多板：取 **最近一次有效放量涨停日** 的成本  
- 若含今日涨停且此前已有板：清洗对象用 **今日之前那次涨停** 的成本  
- **买入时：** 现价须低于 \(C\)，建议低 **3%～8%**（过近没空间，过远可能主力真崩）

### 3.2 有效涨停

- 时间窗：**近 3 个交易日**（含当日复盘时，优先看已完成清洗的前板）  
- 板数：**1 板或 2 板**（3 板以上原则上不做）  
- 非一字板、尽量非纯秒板（选盘中有博弈后封板）  
- 涨停日有真实量能（换手大致合理：过低假突破，过高防一日游）

### 3.3 「主力未走」判定

须同时偏多满足：

1. 回调成交量较涨停日 **明显萎缩**  
2. 尽量 **不破涨停日最低价**（破则降级或放弃）  
3. 个股非持续放量单边崩  
4. 所属板块资金未整体崩塌  

**疑似走了 → 不做：**

- 跌破涨停低点后继续放量暴跌  
- 高位连续大阴、换手异常放大  
- 板块退潮、同概念全灭，个股阴跌无抵抗  

### 3.4 主线

- 近 3～5 日市场热点，或当日板块涨幅 / 资金流入靠前  
- 个股概念 / 行业与主线相关（宁缺毋滥）

## 四、选股过滤

| 条件 | 标准 | 级别 |
|------|------|------|
| 涨停 | 近 3 个交易日有 1～2 板放量涨停 | 必须 |
| 成本 | 现价 < \(C\)，且低约 3%～8% | 必须 |
| 清洗 | 跌破 \(C\) 后有缩量过程 | 必须 |
| 市值 | 流通市值 **50～500 亿**（试验期可先 **80～300 亿**） | 必须 |
| 基本面 | 非 ST；无立案、重大违法、业绩暴雷等 | 必须 |
| 主线 | 靠近近期 / 当日主线 | 必须 |
| 大盘 | 非单边暴跌、非放量破位加速日 | 必须 |
| 板位 | 1～2 板 | 优先 |
| 量价 | 涨停放量、回调缩量 | 优先 |
| 结构 | 未破涨停最低价 | 优先 |

---

## 五、买入规则

### 5.1 时间

- **优先：14:00～14:45**  
- 14:45 后信号不清晰 → 可放到次日再评估，不强迫买  

### 5.2 买点（同时满足）

1. 已满足选股过滤  
2. 分时 **不再创新低**，走平或抬头（止跌）  
3. 下跌变缓，有承接  
4. 同主线其他标的未全面崩盘  
5. 非尾盘突然对倒拉高骗线  

### 5.3 仓位

| 项目 | 标准 |
|------|------|
| 单笔 | 总资金 **3%～5%** |
| 本策略总仓 | ≤ **10%～15%** |
| 同时持仓 | ≤ **2 只** |
| 加仓 | 试验期 **不加仓** |

### 5.4 下单前必设

- 止损价  
- 目标价（成本线 \(C\) 附近）  
- 最晚持有日（默认买入后第 2 个交易日结束前处理完）

---

## 六、卖出规则

| 情形 | 动作 |
|------|------|
| 次日冲高至 \(C\) 附近（±1%～2%） | 卖出 **50%～100%** |
| 次日明显越过 \(C\) 且分时强 | 可留 ≤30%，余下上移止盈；冲高滞涨清掉 |
| 次日高开弱走 | 反抽减仓，不幻想再板 |
| 次日低开 | 反抽走；无反抽且破止损 → 止损 |
| 买入当日尾盘又破止跌低点 | **当日止损** |
| 持有满 2 个交易日仍远离 \(C\) | 评估清仓，不改做成中线 |
| 板块突然退潮 | 优先离场，不等 \(C\) |

---

## 七、止损规则

试验期固定使用：

1. **结构止损：** 跌破买入后确认的分时止跌低点；**或** 跌破涨停日最低价  
2. **幅度止损：** 浮亏达 **-5%～-7%**  

触发任一 → 离场，**不补仓摊平**。

---

## 八、大盘与环境开关

| 环境 | 策略状态 |
|------|----------|
| 指数平稳 / 弱修复，有主线 | **正常做** |
| 有主线但指数大震荡 | **降仓，只做最标准形态** |
| 指数放量破位加速、情绪冰点无主线 | **空仓，不做** |
| 主线一日游已退潮 | **不做该主线回补** |

---

## 九、每日执行流程

### 早盘前（约 15～20 分钟）

1. 定今日主线候选（近 3～5 日热门 + 竞价强弱）  
2. 从主线里筛：近 3 日有 1～2 板、流通 50～500 亿  
3. 算出各票成本线 \(C\)，看谁已在 \(C\) 下方  

### 盘中

1. 盯板块资金是否还在主线  
2. 观察候选是否缩量清洗、是否破涨停低点  
3. **14:00 后** 看分时止跌再决定  

### 收盘后

1. 记录交易或未交易原因  
2. 更新持仓次日计划（目标 / 止损）  
3. 复盘：主线是否切换

## 十、下单检查清单

**缺 2 条以上 → 不做。**

```
□ 近3个交易日有1～2板放量涨停（非一字）
□ 成本线C已计算（涨停日均价或典型价）
□ 现价低于C约3%～8%
□ 回调缩量，清洗过程可见
□ 尽量未破涨停日最低价
□ 流通市值50～500亿
□ 非ST、无重大利空
□ 靠近近期/当日主线
□ 大盘非单边暴跌日
□ 14:00后分时止跌、不创新低
□ 止损价、目标价（C附近）已写好
□ 仓位≤5%，当日策略仓未超限
```

---

## 十一、明确不做的情况

- 无涨停、只是大阴后的「感觉超跌」  
- 放量跌破涨停低点仍在加速砸  
- 3 板以上高位股  
- 流通市值 &lt;50 亿或 &gt;500 亿  
- 纯杂毛、与主线无关  
- ST / 有重大负面  
- 用本策略抄「龙头放量主跌、无涨停成本回补结构」的票  
- 追已经拉回成本线上方的票  
- 大盘破位加速日强行开仓

## 十二、同花顺实操对照（手机）

| 步骤 | 操作 |
|------|------|
| 找近 3 日涨停 | 行情 → 涨停板 / 热点 → 记录 1～2 板标的 |
| 流通市值 | 个股页 / F10 → 看流通市值是否 50～500 亿 |
| 成本线 | 涨停日 K 线：成交额÷成交量；或用 (开+高+低+收)/4 近似 |
| 是否跌破成本 | 现价与 \(C\) 比较，算低幅 % |
| 是否缩量 | 对比涨停日与回调日成交量 / 换手 |
| 是否破板低 | 回调最低价 vs 涨停日最低价 |
| 主线 / 资金 | 板块涨幅榜 + 资金流向（今日累计，刷新看变化）；个股/板块「资金」分时 |
| 两点后止跌 | 分时图：不再创新低、走平或翻红、相对黄线关系 |
| 基本面排雷 | F10 / 公告：排除 ST、立案、暴雷 |

**说明：** 手机版常无「即时资金」选项时，用 **板块资金分时 + 下拉刷新今日净流入榜** 代替。

## 十三、试验期管理

| 项目 | 标准 |
|------|------|
| 前 20 笔 | 严格按清单，不临时改规则 |
| 单日亏损熔断 | 本策略当日合计亏损约 **2%** 资金 → 停手 |
| 连亏 3 笔 | 暂停 3 个交易日，只复盘 |
| 统计 | 胜率、平均盈利、平均亏损、盈亏比、是否按纪律 |
| 优化时机 | 满 20 笔后再改 **一条** 参数 |

### 每笔必记

```
日期 / 代码 / 名称 / 主线
涨停日 / 成本C / 买价 / 卖价
盈亏% / 是否止损 / 是否按纪律
一句话复盘
```

| 体系 | 关系 |
|------|------|
| **本策略** | 闷杀回补短线 |
| 情绪爆发追主线 | 另册；不与本策略叠仓同一只 |

## 十五、决策树（简图）

```
开盘前/盘中
  ├─ 大盘是否破位加速？ → 是 → 空仓
  ├─ 今日有无主线？资金进哪？ → 无 → 空仓
  ├─ 主线内近3日1～2板 → 算C → 现价是否在C下3%～8%？
  │     └─ 否 → 观察，不买
  ├─ 回调是否缩量、尽量不破涨停低？ → 否 → 降级/放弃
  └─ 14:00后分时止跌？ → 是 → 3%～5%试仓，挂止损与目标C
                          → 否 → 不买
```
